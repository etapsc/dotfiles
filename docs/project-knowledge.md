# Project Knowledge

Input-side project knowledge (world → BRIDGE): the background and domain truth
BRIDGE needs when it lands on an existing project. Filled by
`bridge-context-create` / `bridge-context-update` from operator-provided
existing docs (README, PRD, wiki, descriptions) plus targeted code inspection.
Operator-owned after first fill; never silently overwritten — refreshed only
on new sources or explicit request. This is NOT the derived
`docs/project-brief.md` (a BRIDGE → world output that is fully regenerated).
